# Citation Rules

## Citation Principle

Every factual claim in the presentation must be traceable to an approved source. The deck may be elegant, but the underlying evidence must stay auditable.

## Approved Source Types

- User-provided memorial PDF.
- User-provided example presentation.
- Files from the provided Dropbox folder after ingestion.
- User-approved external references.
- User-provided clarifications in this thread, when recorded as assumptions or instructions.

## Source Identifiers

Use stable identifiers:

- `MEM-pNN`: memorial PDF, page NN.
- `EXPDF-pNN`: example presentation PDF, page NN.
- `EXHTML-sNN`: example presentation HTML slide NN.
- `DROPBOX-file-slug`: file ingested from the Dropbox folder.
- `USER-note-YYYYMMDD-NN`: direct user clarification.

## Slide Citation Placement

Use one or more of these methods:

- Small source note on the slide when the claim is central.
- Speaker notes containing full source references.
- Evidence registry entry that maps slide claims to sources.
- Final appendix slide only if it does not weaken readability.

## Claim Classes

- Identity claims: names, titles, institutions, dates.
- Career claims: positions, promotions, administrative roles.
- Teaching claims: courses, students, supervision, programs.
- Research claims: themes, publications, impact, collaborations.
- Service claims: committees, leadership, outreach, institutional work.
- Quantitative claims: counts, metrics, rankings, funding, dates.

All claim classes require a source.

## Forbidden Citation Practices

- Do not cite a source that was not actually read or extracted.
- Do not cite a general source for a precise claim unless the precise claim appears there.
- Do not summarize numbers from memory.
- Do not merge multiple facts into one citation if the source only supports part of the sentence.
- Do not use generated text as a source.

## Citation Review

Before export, run a citation audit:

- Each slide has at least one source when it contains factual content.
- Each number and date has a source location.
- Any `needs_review` evidence item is either resolved or removed.
- Speaker notes and visible citations agree.
