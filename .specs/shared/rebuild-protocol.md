# Rebuild Protocol

## Purpose

This project now uses a controlled rebuild path for the memorial deck after the C4 prototype was rejected for insufficient content density and weak memorial structure.

## Operating Rules

- Do not rebuild the complete deck in one pass.
- Do not treat the C4 prototype as final content.
- Work through Changes 007-013 in order.
- Ask the user for approval before starting each change.
- After each change, provide a review package and wait for approval before continuing.
- During Change 012, ask for approval after each major section.

## Content Direction

- Slides should contain much more memorial information than the C4 prototype.
- Prefer telegraphic cards, visual groupings, timelines, figures, metrics, and equations over long paragraphs.
- The user will provide the full spoken explanation; slides should act as dense prompts and evidence boards.
- Section changes must be visually and narratively clear.
- Figures should come from `memorial.pdf`, the example HTML deck, or approved article/source material.
- Equations must be compiled/rendered, not shown as raw LaTeX source.

## Review Gates

1. Audit approval.
2. Slide architecture approval.
3. Template approval.
4. Figure/evidence library approval.
5. Equation rendering approval.
6. Per-section deck approval.
7. Final export approval.
