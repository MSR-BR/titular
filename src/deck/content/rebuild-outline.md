# Rebuild Outline - Change 008

Date: 2026-07-03

Status: proposed slide architecture for user review. This is not the implemented deck.

## Design Intent

The rebuilt deck should be a dense memorial presentation, not a lightly illustrated CV. The slides should work as evidence boards for a 50-minute talk: telegraphic, visual, source-backed, and technically richer in the physics section.

The visible deck should not show time allocations. The pacing below is internal only.

## Architecture Summary

- Core deck: 59 planned slides, including 7 fast section/title/closing slides.
- Effective content slides: 52.
- Backup deck: 5 optional slides.
- Macro-sections: Abertura, Formacao, UFF, Resultados, Impacto, Internacionalizacao, Futuro.
- Main density rule: Resultados gets the highest technical density, with equations, figures and compact references on slide footers.
- Output style rule: prefer cards, timelines, metric dashboards, figure boards and compiled equation boards over prose.
- Review rule: this outline must be approved before Change 009 redesigns the visual template.

## Density Scale

- D1: section or title slide; minimal text, strong visual hierarchy.
- D2: 3-4 cards or one visual plus short cards.
- D3: 5-7 compact cards, metrics, or timeline entries.
- D4: technical board with compiled equations, figure/result, mechanism cards and references.
